# 004 陷波零点角低频病态 —— **已修**（收口见 [026](026-notch-replaced-by-projection.md)）

> **2026-09-22 收口**：按下面第四次定案的结论换结构，陷波链整个撤掉，改成 4 槽投影相减。
> 实测 60 Hz 单音 −37.06 dB、四音同时最差 −23.96 dB（旧结构是"没有陷波"）。
> **本文以下内容全部保留原样**（含三次误判），因为"怎么一路错到结构问题"才是这份档案的价值。
> 026 的实测表、"投影修好了结构但没修好闭环收益"这两条，见 026。

**症状** 满深度陷波对 60 Hz 只有 **−12 dB**（单级）/ −20 dB（四级级联）。

**误判（两次，都错）**
1. 先归因于"陷波互相重叠吃掉深度" —— 把 ρ 从 0.99 提到 0.9975，只从 −8.95 到 −20.18。
2. 再归因于"双二阶内部状态只有 16 位、被极点放大 1/(1−ρ)=400 倍"。**做了实测，完全无效：**

```
单级 60 Hz  state=16 bit -> -12.31 dB
单级 60 Hz  state=20 bit -> -12.31 dB
单级 60 Hz  state=24 bit -> -12.31 dB
单级 60 Hz  state=28 bit -> -12.31 dB
```

**根因** 直传型双二阶用 `a1 = −2ρ·cos ω0`（Q14）表示陷波频率。低频处 `acos` 病态：

```
60 Hz: w0 = 0.009651 rad
   量化后零点角 = 0.011049 rad = 68.7 Hz   ← 零点不在 60 Hz，跑到 68.7 Hz
```

在 60 Hz 上，**系数 1 个 LSB 的误差 ≈ 零点跑 39 Hz**（`dω/dcoef = 1/sin ω0`）。
Q14 装不下低频陷波所需的分辨率。测出来的 −12 dB 量的是裙边，不是零点。

**修法（候选，都还没验证）**
- **甲**：换耦合型 / 状态变量型，让低频信息由 `sin ω0` 承担而不是 `cos ω0`。
  试过一版但归一化写错，测出 0.00 dB（根本没陷波）—— **既没证实也没否定**，
  要正经设计一轮。
- **乙（倾向）**：不做 IIR 陷波，改成**投影相减** —— 窄带支路已知精确频率（NCO）
  也已在估计幅相（权重 w），直接 `xbb = x − Σ(α_k sin_k + β_k cos_k)`。
  没有频率放置误差，频率变了自适应跟随。顺带能把 6 级双二阶从参考通路撤掉，
  群延迟问题一起消失。

**复现/指纹** 陷波深度**对状态位宽完全不敏感** —— 这一条就能把它和 002 那种
"结构错"分开，也能和真正的量化噪声分开。

## 根因定案（实测，2026-09-21 深夜）

之前的"系数 Q14 精度不够"只说对了一半。**逐项敏感度分析**（把每一项单独换回理想值，看零点回到哪）：

```
理想零点            60.0000 Hz
RTL 量化后          68.6898 Hz
  b0 换理想值  ->  68.6898 Hz   (△  0.0000)   ← b0 无关
  b1 换理想值  ->  48.5707 Hz   (△−20.1191)
  b2 换理想值  ->  84.1268 Hz   (△+15.4369)

cos 的有效位数：
  cos 存 14 位 -> 隐含角 68.689 Hz  (+8.689 Hz)
  cos 存 15 位 -> 隐含角 68.689 Hz  ← 和 14 位一样！
  cos 存 16 位 -> 隐含角 59.486 Hz  (−0.514 Hz)
  cos 存 20 位 -> 隐含角 60.103 Hz  (+0.103 Hz)
```

**14 位和 15 位给出同一个数，说明实际只用到 14 位有效——这正是 Q14 系数的上限。**

### 但真正的根子更靠前：**正弦表只有 1024 点**

RTL 取 `cosω0` 是走 `rom_addr = freq>>22`，这是 **10 位**下标 ⇒
**一个 ROM 下标 = fs/1024 = 38.15 Hz**。60 Hz 落在下标 2 上，
**陷波频率被量化成 38 Hz 的格子**，和系数精度叠加，最后落在 68.69 Hz。

**注意区分两处用同一张表的不同后果**：
- **NCO** 用它出**波形** → 1024 点完全够（误差 0.15 LSB）
- **陷波** 用它定**频率参数** → 1024 点等于 38 Hz 一格，不可用

### 修法（三条，都还没验证）
1. **让 host 直接算 `cosω0` 写寄存器**（`A_NK+3` 现在是保留位），绕开 ROM 下标 —— 最直接
2. ROM 做**线性插值**：误差降到 (2π/1024)²/8 → 0.03 Hz
3. 投影相减（见上），彻底不用 IIR 陷波

### ⚠ 顺带订正：这条**不是**混合 NR 的主要瓶颈

实测（1536 帧，陷波开）：

| | 混合 NR |
|---|---|
| 当前陷波 | 5.87 dB |
| **完美谱分离**（参考里一点音调都没有） | **9.47 dB** |

修好陷波值 **3.6 dB**（5.87 → 9.47）。但**即使给宽带支路一个完美参考，它也没把自己那
10.9% 消掉** —— 完美分离后混合 9.47 ≈ 窄带单独的上限 9.64，说明**瓶颈是窄带**。
**宽带支路交不出活是个新发现的问题，根因还没量。**

## ⚠⚠ 最终结论（实测，第三次也是最后一次订正）

上面那段"宽带支路交不出活"**是错的**。实测（1536 帧，窄带关、只开宽带）：

| 参考 | 宽带支路单独 NR | 它的理论上限 |
|---|---|---|
| 真实参考（陷波后，还带音调） | +20.86 dB | 0.50 dB |
| **完美参考（只含它自己那段）** | **+0.74 dB** | **0.50 dB** |

**0.74 ≈ 0.50，宽带支路是好的。**

**我错在拿错了标尺**：用完美谱分离的 9.47 dB 去比"窄带上限 9.64"，得出"宽带贡献≈0"。
但**宽带支路在 70/30 下的正当上限本来就只有 0.50 dB**（宽带只占 10.9% 功率），
贡献 0.5 dB 就是满分。拿一个不属于它的标尺去量，得出"它坏了"。

**所以卡住的确实是 004：**

```
只窄带（70/30，真实陷波）   7.56 dB
混合（70/30，完美谱分离）   9.47 dB   → 去掉抢频点
混合（70/30，真实陷波）     5.87 dB
                              ↑ 这 3.6 dB 就是 004 的代价
```

**教训**：给一条支路定"该拿多少"时，**上限必须从它自己那段的功率占比算**，
不能拿总体的标尺。这个坑和 005（参数没接上却当成抑制不够）是同一类：
**拿错了因果**。一天之内在同一个问题上改了三次口径，三次都是标尺/归因错，不是数据错。

## 🔴 真因定案（第四次，这次是结构性的）：**直传型双二阶在 Q14 下对低频陷波是退化的**

按"让 host 直接写 cosω0"修完之后实测，**60 Hz 反而更差**：

| 频点 | ROM 取 cos | host 写 cos |
|---|---|---|
| 60 Hz | −12.27 dB | **−2.22 dB** ← 更差 |
| 120 Hz | −8.19 | −8.19 |
| 180 Hz | −2.73 | **−6.94** ✓ |
| 240 Hz | −8.54 | **−15.66** ✓ |

（混合 NR 反而从 5.87 升到 6.69 —— 四个音里三个变好、60 Hz 变差，净收益 +0.82。
**但这不说明修好了**，只说明一个退化的零点被换成了另一个位置。）

### 机理：`b1 = −32766` 让零点从"复共轭"退化成"两个实零点"

零点半径式要有陷波，必须有**复共轭零点**，条件是 `disc = b1² − 4·b0·b2 < 0`：

```
b0=16384  b1=−32766  b2=16382
4·b0·b2          = 1,073,610,752
b1²              = 1,073,610,756
disc             = +4        → 两个实零点（z=1.0 与 z=0.99988），**没有陷波**
```

**分界线是 `b1 ≤ −32765`。** 而 60 Hz 的理想值是 `−32765.5` —— **正好压在刀锋上**，
取整往哪边偏就决定这个滤波器是陷波还是低通。

所以之前三次"精度不够"的说法都不对：**不是精度不够，是直传型在 Q14 下对
`ω0 → 0` 的陷波本身退化了。** 低频陷波要求 `b1 ≈ −2` 且 `b2 ≈ 1`，
而"是不是陷波"取决于 `b1²` 与 `4b0b2` 两个接近 2³⁰ 的数谁大 —— 差 4。

### 结论：**换结构，不要再调系数**

候选（都**还没验证**）：
1. **耦合型 / 状态变量型**（Gold–Rader）：让低频信息由 `sinω0` 承担，不构成 `b1=−2cosω0`
   这个退化量。**之前试过一版但归一化写错，测出 0.00 dB —— 既没证实也没否定。**
2. **投影相减**：`xbb = x − Σ(α_k sin_k + β_k cos_k)`，频率由 NCO 精确已知，
   **完全不经过双二阶**，绕开整个退化问题。倾向这条。

### 已经落地的改动（保留，但不构成 004 的修复）
RTL 加了 `A_NK+3` = host 写的 `cosω0`（Q15），没写就退回 ROM 查表。
它把 180/240 Hz 的陷波改善明显，但对 60 Hz 无效。**留着它是因为换结构后可能还要用**，
不是因为它是修复。
