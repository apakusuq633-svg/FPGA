# 026 陷波链换成投影相减 —— **部分复核**

`004` 的收口。6 级双二阶链（2 带通 + 4 陷波）从参考通路整个撤掉，换成 4 槽最小二乘投影相减。

**症状**（承接 004，实测）直传型双二阶在 Q14 下对低频陷波**结构退化**：
`b0=16384 b1=−32766 b2=16382` ⇒ `disc = b1²−4b0b2 = +4` ⇒ 两个实零点，**没有陷波**。
理想 60.0000 Hz，实际零点 68.6898 Hz。要复共轭零点得 `b1 ≤ −32765`，而 60 Hz 的理想值
是 `−32765.5` —— 正好压在刀锋上。**状态位宽 16→28 位实测一位都不动**，所以不是精度问题。

**误判（三次，都记在 004）** ①陷波互相重叠 ②双二阶状态位宽不够 ③系数 Q14 精度不够 /
ROM 下标 38 Hz 格子。三次都在调**系数**，而结构本身已经退化 —— 系数怎么调都调不出来。

**根因**
1. **结构性**：DF-I 用 `a1 = −2ρcosω0` 表示陷波频率。低频处 `cosω0 → 1`，
   "是不是陷波"取决于 `b1²` 与 `4b0b2` 两个接近 2³⁰ 的数谁大 —— 差 4 就换个结论。
   投影相减**全式没有 b1**：频率只由 NCO 相位累加器给，退化问题连带 6 级群延迟一起消失。
2. **实现性（本次新踩的坑，比上面那条更值钱）**：Verilog 里**有符号移位不能和拼接共用一个运算符**。
   ```verilog
   wire signed [33:0] cor_next = {{2{state[31]}}, state} + (diff >>> PROJ_S);  // ← 错
   ```
   `+` 左边是拼接 ⇒ 拼接**永远无符号** ⇒ 整个表达式按无符号算 ⇒ 移位被拉成**逻辑**移位。
   症状极隐蔽：`state` 还小于乘积时（`diff > 0`）算术/逻辑移位结果**完全相同**，
   等 `state` 追上乘积、`diff` 第一次变负那一帧起，每帧多涨 `2³⁴/2¹² = 4.19e6`，
   几千帧后把估计值顶到饱和。实测指纹：**t=288 帧逐位相等，t=320 帧差 4.3 倍**；
   α 从 16000 一路涨到回绕成 −32767。
   > RTL 和模型对不上时该信谁：**信模型**。Python 的 `>>` 对负数是算术移位，
   模型是对的；RTL 多算了。证据就是上面那条逐拍 dump：`diff=-30054013` 而
   `next-state=+4186966=(2³⁴−30054013)>>12`。

**修法**
- `rtl/anc/rv32_anc_regs.v`：删掉 6 级双二阶链（`st_x1/x2/y1/y2`、`sel_b0..a2`、
  `nkc_*` 系数流水相位、`bp_*` 系数寄存器）。**带通两节一并删**：007 实测参考通路上挂 IIR 带通
  要赔 19 dB，默认就该是没有。
- 新数据通路（每槽）：
  ```
  p  = x · sin_k                                // Q15×Q0 → Q15
  ls = ls + ((p − ls) >>> PROJ_S)                // 一阶泄漏积分，S=12
  α  = sat16(ls >>> 14)                          // = 2·mean(x·sin)，2/N 折进这个 14
  ta = sat16((depth_k · α + 16384) >>> 15)       // 深度缩放，四舍五入
  pa = ramp16(pa, ta, nramp_step_q)              // §15 的渐变插入，保留
  y  = sat16(x − ((Σ pa·sin + pb·cos + 16384) >>> 15))
  ```
- 序列 **68 拍 → 50 拍**（`S_END`=50）：`0..7` 发 NCO 地址、`2..9` 收数（两拍延迟，见 011）、
  `10..17` 相关、`18..25` 渐变、`26..33` 相减、`34..49` 窄带 MIMO、`50` 收尾。
  每帧省 18 拍 ≈ 序列长度减 26%。
- 有符号移位全部拆成独立 signed 线（`cor_prod_e/cor_state_e/cor_diff/cor_delta/cor_next`），
  绝不把移位塞进带拼接的表达式里。同样的隐患在 `rmp_shift` 上一起清掉。
- 寄存器语义：`nk_en` 仍然门控音调；`nk_rho_q`（`A_NK+1`）**变成哑寄存器**（读写自洽、不参与运算，
  保留读写口是因为 `sw/ps_anc.c` 拿它做 ANC 窗口在位自检，那份文件归另一条工作流）；
  `A_NK+3` 从"host 写的 cosω0"改成**读** `{β_k, α_k}`。`NOUT`/`NIN` 语义不变。
- `scripts/gen_anc_hybrid.py`：`NotchBank` → `ProjectionBank`，逐位复刻同一套算术、同一截断、同一运算次序。
  重新生成产物后 **8 个文件 md5 全部不变**（`anc_expect.hex` = `89d0c1531f4bf1aa5fe618079e32beb8`）——
  这是"旁路逐样点恒等"的强证据，也说明改写没碰到别的路径。

S 的选取：**定 S 的是四音同时那条最差曲线，不是单音**。S=11 → 240 Hz 只有 −18.1 dB（够不到
−20 dB）；**S=12 → −24.1 dB**；S=13 → −30.1 dB。取 S=12：τ = 4096 样点 = 105 ms，正好一个 PS 音调帧。
单音 S=12 能到 −37.9 dB，四音最差只有 −24.1 dB —— 差的那 13 dB 是**互调与串扰**，不是深度不够。

| 配置 | C 只窄带 | D 只宽带 | E 混合 |
|---|---|---|---|

| 旧陷波链开（004 记录的历史值，非本次重跑） | 7.56 | 3.07 | 5.87 |
| **投影开** | 7.56 | 15.95 | **16.75** |

⚠ **两件必须说清楚的事**：
1. 投影把混合从 5.87 抬到 **16.75（+10.88 dB）**，比 004 自己估的"陷波值 3.6 dB"大得多 ——
   004 预测但没量到的**群延迟代价**确实存在。
2. **但它仍略低于"完全不陷波"的 16.93**，而且 D 从 20.86 掉到 15.95。所以本次修好的是**结构**
   （无退化零点、无群延迟、四音 24 dB），**不是闭环收益**。要不要把投影打开是**控制律**问题
   （参考通路去掉音调等于抽掉宽带支路正在用的信息），需要另一轮标定 —— 见 §40.6 / §40.9。
   产物与 `tb_anc_hybrid` 都保持 `en=0`，与 `configure()` 对齐。
   ⚠ 顺带记一笔：`sw/ps_anc.c` 里 `ANC_NOTCH_EN` **默认是 1**，即**板上跑的是投影打开**，
   和所有主机侧黄金对照的配置不一致。这是上面那条控制律问题的具体后果。

**复现/指纹**
- **逐位恒等式必须跑到 2500 帧**。头 ~280 帧里 `diff` 恒正，算术/逻辑移位结果相同 ——
  跑 120 帧的恒等式**对符号毫无分辨力**，本次就是从这个窗口漏过去的。
  配套断言：`|ls| ≤ 32768·32767` 必须恒成立；跑飞时能看到每帧固定 +4.19e6 的爬升。
- 恒等式要用 64 位整数在 TB 里**重算**，不比统计量。`α/β` 与 `sin/cos` 都读得回来
  （`A_NK+3` 与 `nco_raw_q`），所以相关器和相减两条都能逐位对。
- 结构指纹（004 那条仍然有效）：陷波深度**对状态位宽完全不敏感**。
- 新结构指纹：**抑制深度随频率升高而变好**（−37 → −50 dB，2ω 纹波相对泄漏积分拐点更低）。
  IIR 陷波是反过来的 —— 这条一眼就能分开两种结构。
- 反空转：**输出被卡成 0 也能让"衰减够深"通过**（004 记过一次"假过"）。
  所以每条衰减判据都带 `out > 1` 门槛，另查输入幅度是否等于激励幅度、`sqrt(α²+β²)` 是否等于音调幅度。

**状态**：部分复核。**已实测**：RTL 逐位恒等式（各 2500 帧）、单音/四音抑制、带内透通、
插入渐变、旁路恒等、`tb_anc_hybrid` 逐位不变（1536 帧 0 mismatch）、`tb_anc_nco` 通过、
产物重生成 md5 全同。
**未实测**：①**时序**——序列从 68 拍缩到 50 拍，面积/时序影响没跑 Vivado（本工作流不跑），
`020` 那条 WNS 结论不能套用；②**板级**——没有上板数据，`ps_anc.c` 的 `ANC_NOTCH_EN=1` 后果未知；
③旧陷波链的两行闭环数取自 004 记录，不是本次重跑（代码已删）。
