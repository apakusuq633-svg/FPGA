# 008 窄带次级通路虚部符号

**症状** 窄带权重**一拍撞死在 ±32768**，输出顶在限幅上。

**误判** 一开始只当成"μ 太大"，把 `MU_NB_NUM` 从 2^25 降到 512 ——
从撞死变成收敛到 4.5 dB 就不再改善，**看起来像"算法就到这了"**。

**根因** 参考经 ŝ 之后的相位关系推错。正确是：

```
sin 经 ŝ 之后 = A·sin(ωn) − B·cos(ωn)
cos 经 ŝ 之后 = A·cos(ωn) + B·sin(ωn)
其中 A = Σh·cos(ωt)、B = Σh·sin(ωt)
```

`sin` 那一项的虚部是**减**号。写成加号不是"收敛慢"，是**发散**（更新方向反了）。

**修法** 改成减号。并且在脚本开头留了一段**冲激实测**把这条钉死：

```
actual=-0.364127   A*sin-B*cos=-0.364127   A*sin+B*cos=-0.441322
```

**复现/指纹** 权重撞死在满量程边界 —— 这是**方向错**的指纹；
μ 太大会发散得更快但不会正好停在边界上。符号问题一律用冲激/单频实测钉，
不要靠推导，推导在这里已经错过一次。
