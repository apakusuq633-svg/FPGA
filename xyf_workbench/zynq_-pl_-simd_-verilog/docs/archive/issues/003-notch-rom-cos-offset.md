# 003 陷波 ROM 取址少 +256

**症状** 陷波的中心频率跑到 **fs/4 − f**（60 Hz 的陷波实测中心在 9727 Hz）。

**根因** NCO 那条路取 ROM 时带了正交偏移：

```verilog
rom_addr_q <= phase_q[...][31:22] + (step_q[0] ? 10'd256 : 10'd0);
```

陷波那条路要的是同一个角的 **cos**，却漏了 `+256`（整周四分之一），拿到的是 sin。
于是 `c1 = 2ρcosω` 实际拿到 `2ρsinω`，极点角变成 π/2 − ω。

**修法** 陷波路也加 `+ 10'd256`。

**复现/指纹** 陷波在**完全不相干的频点上生效**（实测 9727.478 Hz 处 −46.9 dB，
而 60 Hz 处 0.00 dB）。极点角错成 π/2−ω 时，`fs/4 − f` 这个位置是可以直接算出来的。
