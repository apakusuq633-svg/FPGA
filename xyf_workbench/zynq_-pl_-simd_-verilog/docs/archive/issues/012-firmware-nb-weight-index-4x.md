# 012 固件里窄带权重索引大了 4 倍

**症状** `tb_anc_hybrid` 首个数据分叉在第 **17** 帧，固件 `0x0016ffff` vs 黄金 `0x002affff`。

**误判** 先怀疑 TB 的预装或 RTL 的地址译码 —— 都查了一圈。

**根因** `gen_anc_hybrid.py` 发射固件时把窄带权重索引按**字节偏移**算，
`widx = 4*(s*8+k*2)`、cos 再 +4；而 `rtl/anc/rv32_anc_regs.v` 的
`nb_idx_q <= wdata[5:0]` 是**字**索引（`nb_wmask_q[nb_idx_q[3:0]]`、`nb_t[3:0]`）。
只有 NCO 地址那条（NOFF）确实是字节偏移、必须保持 `4*k`。

**修法** 权重的 `widx` 去掉 ×4。

**复现/指纹** `NBSTAT` 读回 **`16'h1111`** —— bit 0/4/8/12，正好是 4 倍间距折进
16 位掩码窗口的指纹。**这就是为什么 `NBSTAT` 这个寄存器值得留着**：
一个本该是 `16'hffff` 的掩码给出等差数列，索引定标错了是唯一解释。
