# 002 双二阶链收尾跑飞

**症状** ANC 的陷波输出 `NOUT` **恒为 0**，看起来像"陷波根本没生效"。

**误判** 先怀疑系数算错（那个方向也确实另有问题，见 003），改了系数毫无变化。

**根因** 序列发生器里链的执行条件是

```verilog
end else if (step_q > S_BQ && step_q < S_END) begin
```

但**双二阶只有 30 拍活干**（步 15..S_NB-1），`S_NB` 之后是窄带那 16 拍。
上界写成 `S_END` 会让步 `S_NB..S_END-1` 反复重跑 `tap_q == 4` 那个分支 ——
而 `sec_q` 已经是最后一节、不再自增，于是 `cur_x_q` / `acc_q` 每拍被同一个分支覆盖。
到 `S_END` 收走的是跑飞值。

**修法** 上界改成 `S_NB`。一行。

**复现/指纹** 逐拍 trace 序列：正常跑到步 44 就冻结在 `sec=5 tap=4`，
`curx` 在 0 / 14808 / 0 / −14513 之间摆 —— **输出在零附近来回跳**是这类
"重复执行同一个收尾分支"的特征。
