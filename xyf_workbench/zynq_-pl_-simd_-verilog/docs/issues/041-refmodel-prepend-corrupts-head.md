# 041 CIC 参考模型用 `prepend` 补首元素 ⇒ 头部被污染成超界值

**症状** `scripts/golden/pdm_decim.py` 的 §4 报「定点回绕与精确值不一致」，
所有位宽（20/22/24）全部不一致。打印出的「实测最大 |输出|」是 **312000**，
而理论上界是 `D^N = 64^3 = 262144`。**参考值越过了它自己的数学上界**。

**误判** 第一反应是定点回绕实现写错了（累加器位宽不够 / 补码读回不对），
于是去加大位宽、去改 `sgn()`。方向错了 —— 越界的是**参考**，不是被测的那一侧。

**根因** `cic_ref` 用 `np.diff(x, prepend=x[0])` 补首元素保持长度。
但 `prepend` 把**每一级的首元素清零**，级联 order 次之后，头部几个值变成
「没做减法的原值」。CIC 的输出是输入的非负系数线性组合（Σcᵢ = D^N，cᵢ ≥ 0），
所以真值必定 ≤ D^N；而污染后的头部不再受这个约束，于是出现 312000。

稳态值一直是对的（262144），错只在最前面几拍 —— 所以「看一眼末尾对不对」
这种检查法完全抓不到它。

**修法** 改用裸 `np.diff(x)`（长度每级少 1），并在文档里写明「前 order 个输出是瞬态，
由调用方丢弃」。同时把 §4 的判据从
`(ref-got) mod 2^w == 0`（见 042）改成 `got == ref`。

**复现指纹** 参考模型报出的幅值**超过它自己的解析上界** —— 只要出现这个组合，
先怀疑参考模型的补边/对齐，不要去看被测实现。
