# 102 定位数值恢复之后仍会无声乱报与跳点

状态：数字验证已修；真实阵列效果待验收。

**症状**：四麦实板点位漂移；旧判断只要best>second就发布，无有效声源的合成场景中四麦25/59、16麦48/59被当作有效方向。

**误判**：把网格加密或网页平滑当作定位可靠性改善；把相邻格的第一、第二名差距当作不同声源主峰间隔。

**根因**：直流偏置占用定点有效位；独立噪声也会有唯一最大格；主瓣相邻格可近乎等分；缺少输入/空间质量判断和时间确认。

**修法**：统一`fw_location_quality.h`，先去直流再调整幅度；输入电平/削顶、每对峰值和主瓣外分离度门限；小抖动保持，初始2次/远跳3次确认。无效时不写中心且不更新DAS方向；PS/中文页面显示原因及候选/确认格，兼容旧固件。

**复现/指纹**：`python scripts/check_location_robustness.py`与`python scripts/check_ps_apps.py`。每种阵列59个无效场景误发布降到0，16个有效源均通过；宿主状态机120次相邻格变化保持单格，孤立跳变拒绝。这是定点软件与状态机验证，混响、真实噪声和移动延迟须上板另测。
