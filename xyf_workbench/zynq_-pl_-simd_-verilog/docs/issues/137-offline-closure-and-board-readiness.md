# 137：九麦离线工作收口与上板准备（2026-10-27）

## 交付范围

本轮不上板、不向板卡发网络请求、不修改RTL/XDC、采样参数、几何表、GCC/SRP/DAS/分离算法、18维特征或模型权重。保留旧发布包。生产修改仅为用户明确同意的原始连续PCM导出：sw/circular9_window_export.h、sw/ps_circular9_gui.h，以及build_ui_pipeline.ps1的编译移除选项。导出默认关闭，GUI不会自动启用。其他变更均为宿主测试、仿真与分析工具。

## 完成的离线清单

- 真实C任务异步交错9组：circular9_async_schedule_test.c运行真实CPU0/CPU1调度、历史、FFT、分离、诊断和API，在CPU1声明成本期间持续推进CPU0采集/排队/接收。属于确定性回调交错，不是操作系统线程/cache或ARM实际计时；输入是2.56秒模拟PCM重复。
- 20秒生命周期4组（每组380个搜索窗口）：故障源反复启停、全部关闭后恢复、反复交叉、带噪双源。验证静音6~9秒旧快照不新鲜、无新诊断，恢复后约1.326秒重新有两个新鲜结果；故障源长期消失再出现分配新角轨迹ID。交叉后不保证物理设备身份，这是角跟踪能力边界。
- 纯本地PCM回放工具replay_c9_pcm.py：严格校验9路s16le/156250Hz、长度和哈希，默认不确认几何/校准/RPM、不启用实验模型；10秒模拟录音回放序列18。6项非法参数/防覆盖检查通过。来源只按元数据记录，不将宿主回放称作硬件验证。
- 18组现有离线回归全通过：采集流、接收、提议、轨迹、调度、诊断、包络、管线、辅助搜索、候选、方向、校准、PS控制、加载、峰竞争、快照、模型发布、支持位图。完整GUI/API/健康状态机/SQLite历史测试通过。
- 控制RTL原测试台使用XSim通过（原Verilator路径缺失；XSim仅设置默认timescale，未改RTL）：原子方向事务、别名/部分写/时代/TTL拒绝、600/1200rpm过滤和超时。不是综合实现或实板。
- 全网格投影残差研究14个固定窗口：可在两组弱滚动体窗口中找到约47.8度、距真值约3.56度的残差方向，但单源对照也会产生额外残差峰，近角度/三源未稳定解决。因此仅保留研究脚本probe_c9_residual_search.py与结果，未迁入生产。真值不参与干扰方向选择，使用原候选0；研究扫描为高频带、1024格，计算量远高于现有最多9个次峰支持检查，未测ARM。

## 对此前判断的修正

±70度正常源附近峰46/47，并不表示46次都是合格独立峰。细查突出程度门控后只有4/47通过，最终2/47入选。不能简单归为“取前三峰取错”。另一源持续通过。质量低、峰偏移和竞争必须分层处理；未降低质量阈值。

## 连续PCM导出与验证

POST /api/debug/window/enable 手动开启；GET /api/debug/window?frames=16640或160256 冻结一段同session/epoch原始PCM；GET token/offset/count 分块读取；POST /api/debug/window/disable 关闭并撤销token。默认返回403，编译移除版返回503。启用仅适用于受信任板卡局域网，无身份认证；工具不会后台轮询。

CPU0拥有独立缓存，不复用CPU1工作区、不冻结PL、不改DMA ACK；每64点调用既有实时采集检查点。失败复制/时代变化使旧token失效，不允许拼接不同采集窗。新捕获撤销旧token，关闭撤销访问；chunk带首样本/时代/session/offset/总长。原有短快照接口保持兼容。

原生API测试完整160256×9个样本、157块逐样一致，测试旧token、生产者推进、越界/溢出/负数、复制失败、时代变化、关闭和小响应缓冲；客户端下载9项模拟故障检查通过，失败后尝试关闭，关闭失败明确报告而不丢弃已正确下载的文件。没有真实网口下载或吞吐实测。

160256原始点=1.0256384秒，含256点前端预热；16640原始点=106.496ms，不能混同1.024秒诊断窗或1024点定位窗。

缓存对象2884636字节；受链接对齐影响，BSS总增量3MiB。普通应用_end=0x01159850，低于0x04000000应用区上界；DMA=0x08000000、任务=0x09000000、历史=0x0A000000，预留段地址不变。含导出支持版默认不写缓存、不发送原始PCM；手动触发时复制对CPU0/HTTP/DMA的实际影响必须上板量，不宣称没有时延。

## 上板与取证顺序

1. program_latest.ps1 -Program -OpenPage，检查9路原始输入、搜索处理耗时/间隔、轨迹obs/覆盖、诊断started/completed与有效快照。
2. 固定宽带单源先验收管线；FSTF实验分类另确认1800rpm。模型和几何/校准标志不因仿真而自动确认。
3. 需要连续取证时显式运行scripts/capture_c9_window.py --enable --frames 160256 --output新目录；默认IP192.168.2.10，工具启用一次并finally关闭。输出audio.pcm、metadata.json（哈希/帧号/时代/session），再交给本地replay_c9_pcm.py回放。协议不证明固件身份，取证时同时保存当前发布manifest与烧录日志，避免版本混用。
4. 再测两独立声源±50度、强弱差6/12dB，记录连续原始PCM。未将全网格残差研究部署进生产。
