# 114：SIMD白化的真实指令接入

状态：已修，真实指令、两模拟器、连续整机及完整时序通过；实际声场效果待测。日期：2026-10-14。

## 症状

原备用复数核未被生产固件调用。接入后发现PUSHA/B译码错误，弱互谱归一化为0；修复分项后连续第3帧与参考不一致。

## 误判

模块单测通过不代表CPU桥接正确；改善LUT算术不代表整机及定位可以直接验收。把函数改为automatic没有消除第3帧差异，不能把它归因于函数局部变量共享。模型精度结果不是房间录音结果。

## 根因

IO bank选择错误地来自instr[31]/[28]，而指令要求funct3低两位。16位倒数在小幅互谱时先移位会溢出。第3帧phase382时4104个FFT缓存字全部匹配，896个环样点822个不同，首格15394对参考15077。逐级导出后定位到首对麦的第36个PHAT频点：互谱(6,1)、幅度6，Icarus给LUT10402，XSim 2020.2给15888。条件依赖的降序最高位查找在两个模拟器中不一致；升序无反馈查找消除了差异。这里记录实际工具行为，不将单次复现外推到其他版本。

## 修法

使用instr[13:12]区分PUSHA/B/POP；寄存LUT尾数和指数，先乘再移位输出Q14；共轭虚分量扩为17位，正确表示-(-32768)。最高位改为升序无反馈写法。新增真实固件指令桥接验收、弱频点/全部幅度的双模拟器测试及多帧诊断导出。独立8麦构建默认simd_lut_q14，`--scalar-phat`保留除法对照；其他规模并未在无几何时执行白化。
