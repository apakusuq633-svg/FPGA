# 120：核轮询引起逐窗结果间隔抖动

状态：已修（256窗SoC仿真）。

## 症状

各窗计算均小于Hop，仍偶有524289或524296拍结果间隔，严格最大间隔验收失败。

## 误判

平均吞吐和最大计算耗时达标不能推出每个结果间隔都不超过524288拍。

## 根因

核轮询和指令发射相位变化，若计算结束立刻发布，则相邻窗口延迟差会进入结果间隔。

## 修法

保留独立compute_cycles，在固定窗口相位发布已算好的当前窗口。SoC RESULT_OFFSET=393216，计数边沿下外部实测393217拍。没有丢弃窗口、重复旧结果或仅修改日志。

## 复现指纹

`build/localizer12/final256/simulation.log`：256窗最大计算323568拍；发布时间均393217拍；255个结果间隔全524288。严格报告PASS，audio131968/131968/drop0。固定相位也不能掩盖超时，长HALT负例检测到窗口损失。
