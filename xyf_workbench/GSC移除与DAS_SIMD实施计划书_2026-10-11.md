## 一、项目目标与方案结论

将项目主线调整为“八通道 PDM 采集、声源定位、转向控制、DAS 定向拾音、SIMD FIR 加速”。移除 GSC 的阻塞参考、自适应干扰估计和 NLMS 权值更新支路，保留 DAS 作为最终波束形成方法。

本方案保留声源定位与定向增强，降低算法调试复杂度。其能力边界是固定权重的空间滤波：能够通过延迟对齐增强目标方向声音，但不再提供 GSC 的自适应干扰抵消和逐样点权值收敛。

SIMD-MAC 的首个正式应用确定为 DAS 输出后的固定 FIR。此路径容易与现有历史存储及点积指令匹配，也便于独立验收。随后按声学指标决定是否扩展八路历史存储，使阵列承担分数延迟 FIR 或 CIC 补偿 FIR。后两项以性能和资源评估为前置条件，不作为首版必做承诺。

最终项目表述建议：**基于 Zynq 与 RV32 自定义指令的八通道声源定位及 DAS 定向拾音系统，使用八 lane SIMD-MAC 加速音频 FIR 滤波。**

## 三、范围与交付物

### 3.1 首版必做

1. 产品固件退出 GSC 的标量与 SIMD 计算，不再初始化或检查 GSC 权值。
2. 保留八通道采集、FFT/GCC-PHAT、SRP、转向和 DAS。
3. 建立真实 PCM 到 DAS 的连续数据路径，并实现每路历史缓存与跨帧延迟。
4. 保留八 lane SIMD-MAC，以 `PUSH` 与 `VRED` 执行 DAS 输出 FIR。
5. 建立同输入的标量 FIR / SIMD FIR 对照，检查逐样点结果、动态指令和总耗时。
6. 完成匹配源码、位流、初始化文件、固件及 ELF 的板卡验收。

### 3.2 后续按条件扩展

- 八路分数延迟 FIR：只有线性插值的幅相误差影响目标频带时再实施。
- 八路 CIC 补偿 FIR：先量化通带下垂及噪声放大，再决定是否放在定位与 DAS 前。
- 再抽取：仅在整机预算确有需要时设计；必须重新生成 FFT 频带参数、GCC 延迟、SRP 几何 LUT 和转向参数。

首版不扩展到 16 通道或 32 lane，不增加 ANC、回声消除、MVDR 或新的神经网络任务。

## 四、目标架构与 PS / PL 分工

```text
8 路 PDM
   |
PL 时钟 / CIC / 通道对齐 / 双 bank 采集
   |
帧接收与八路历史管理
   |---------------------------------------|
定位支路                                  音频支路
FFT -> GCC-PHAT -> SRP                     每路延迟补偿
   |                                      |
格点 / 置信度 -> 转向参数 ----------------> DAS 求和
                                          |
                                   SIMD-MAC 固定 FIR
                                          |
                                   PCM 输出 / PS 导出
```

首版保持现有 PS 控制和 PL RV32/加速单元分工：PS 负责启动、配置、帧交接、日志与输出，PL 完成已有采集和加速计算。具体生产输入如何送到 RV32，必须先核查当前 MMIO、DTCM 和采集窗口可达性。

若采集数据目前只能由 PS 消费，先建立 PS 搬运的小块输入协议，并测量搬运开销。禁止把大帧直接塞进已紧张的 DTCM；采用有界分块、环形缓存或可达存储窗口，并明确所有权。若实测仍无法达到音频期限，再在阶段门禁处选择流式接口或 PS 执行部分定位计算，并重新公布分工与实测指标。

定位按帧更新，DAS/FIR 按连续样点或小块处理。定位更新可以低于音频处理速率，音频侧使用最近一次有效方向；方向突变使用渐变或交叉淡化，避免点击声。不能通过重复输出旧音频掩盖超时。

### 阶段 1：退出 GSC 产品路径（预计 1～2 个工作日）

- 修改 `sw/fw/fw_main.c`，移除产品流程中的 `fw_gsc_run()` 及对应计时。
- 修改 `sw/ps_main.c`，取消 GSC 权值初始化、适应性和收益判据，替换为真实 DAS 与 FIR 验收。

- 检查 `fw_mem.h`、`link.ld` 和回读地址：当前转向结果区依附 GSC 尾部，先迁移再回收旧区域。
- 移除产品文档中的 GSC 必选要求；保留旧结果作为标注清楚的历史资料。

门禁：新镜像可编译、链接、启动和回读；既有 FFT/GCC/SRP/转向结果仍正确，产品运行不再调用 GSC。

### 阶段 2：真实 PCM 的 DAS 通路（预计 3～5 个工作日）

- 新建独立生产内核，以八路同一时刻的 PCM 或有界输入块为接口，不在热路径生成测试声源。
- 为每路维护独立历史，容量由最大补偿延迟、插值所需样点和块边界决定。
- 首版采用整数延迟加线性分数插值，统一 Q 格式、舍入、负数行为和饱和。
- 以八路对齐后平均作为基线；验证转向延迟符号、参考通道和公共延迟。
- 把帧序号、有效样点数、READY/ACK_SEQ/RELEASE 与输入所有权接通。
- 实现方向有效性处理：无有效定位时保留上一有效方向，并记录状态；明确启动时默认方向。

门禁：离线输入与独立参考逐样点一致；跨块不断裂；同一真实录音下能够生成单麦和 DAS 对照输出。

### 阶段 3：SIMD-MAC 输出 FIR（预计 2～4 个工作日）

- 根据目标频带设计固定 FIR；首轮可评估 16、32、64 抽头，最终长度由指标决定。
- 利用 `PUSH` 更新单路历史，`VRED` 对历史与系数做点积；保留标量参考。
- 系数启动时装载并回读，产品热路径不更新权值，不依赖 `VUPD`。
- 单独测量装载、PUSH、VRED、调用和块交接开销，核查有效抽头与八 lane 对齐。
- 先检查现有 `VMUL`、归一化和更新相关状态是否还有其他依赖；不为精简而影响复用功能。

门禁：定点逐样点一致、频响达标、FIR 总周期优于同口径 RV32 标量版本。若调用成本抵消收益，优化块接口或记录不达标，不以 MAC 理论吞吐替代实测。

### 阶段 4：按指标决定八路 FIR 扩展（预计另需 3～6 个工作日）

该阶段为条件扩展，不阻塞首版完成。

- 分数延迟方案：使用八路独立历史和相位系数，处理整数偏移与分数相位；不能沿用仅取最新历史的点积而遗漏整数延迟。
- CIC 补偿方案：按现有采样率和目标频带设计，限制高频增益，避免补偿放大噪声。
- 对数据 bank、系数 bank、读地址和状态隔离逐项设计，评估通道串行复用与多 bank 方案。
- 多通道相同 FIR 必须具有一致群时延；分数延迟 FIR 的相位切换也须控制瞬态。

门禁：存在可量化的幅相或增强收益，并且资源、最坏耗时、时序均通过。收益不足时保留线性插值与单路输出 FIR。

### 阶段 5：集成、实现与真实板卡验收（预计 3～5 个工作日）

- 重建参考数据、固件镜像和 ARM ELF，检查源码与镜像标识一致。
- 运行真实核 RTL 的应用级验收及负例。
- 完成产品顶层综合、布局布线、建立/保持时序检查和资源统计。
- 使用匹配本次源码的位流、初始化资料和 ELF 上板。
- 在真实八路麦克风输入下执行连续采集、定位、DAS 和 SIMD FIR，保存原始输入及输出。

门禁：达到第七节指标，且证据可复跑。仿真、综合、ARM 编译、板卡合成场景、真实声音五类结果分别记录。

## 六、实时性与资源预算

当前默认 PCM 采样率为 39,062.5 Hz，对应每个八通道同步采样时刻 25.6 μs。若 RV32 实际运行于 40 MHz，则每个同步时刻约有 1,024 个时钟周期。

1024 点非重叠块的输入时间为 26.2144 ms，对应 1,048,576 个 40 MHz 周期。若使用重叠帧，期限以 hop 大小 H 计算，即 `H / Fs`，不能继续使用完整帧长度作为处理预算。

建议将音频生产路径最坏耗时控制在期限的 80% 以内，剩余预算用于交接和波动。例如非重叠 1024 点块目标约为 838,860 周期。该数字是设计目标，不是已有成绩；定位、搬运、DAS、FIR 和输出都必须纳入共享资源预算。

每阶段报告以下数据：

| 指标 | 统计口径 |
|---|---|
| 周期 | 单路生产计算及端到端周期；另列对照测试开销 |
| 墙钟 | 实际频率下的处理时间和板上端到端时间 |
| 最坏耗时 | 连续运行中的最大值、超时次数和丢帧次数 |
| 定位刷新率 | 实际更新频率、hop、窗口大小和有效方向比例 |
| 资源 | 产品顶层 LUT/FF/BRAM/DSP，另列阵列与新增缓存占用 |
| 时序 | 实现后 WNS/WHS、约束覆盖及未约束路径 |

删除 GSC 固件不会自动删除 SIMD-MAC 的 DSP 或存储。首版保留阵列；若进一步去掉更新硬件，必须通过依赖检查、综合差分与回归证明资源收益和功能正确性。

## 七、验收标准

以下数值为拟定目标，在阶段 0 固定为验收配置；目标频带默认按现有 200 Hz～8 kHz 评估，具体用途变更时先修订配置。

| 项目 | 验收要求 |
|---|---|
| GSC 移除 | 产品调用图与镜像不含 GSC 执行入口；生产运行不执行权值更新；转向地址不受移除影响 |
| 采集 | 八路同步，帧序号连续，连续 10 分钟无丢帧、覆盖未消费 bank 或超时 |
| DAS 数值 | 独立定点参考逐样点一致；覆盖正负满幅、零输入、跨块历史、不同延迟和转向更新 |
| FIR 数值 | SIMD 与独立定点参考逐样点一致；浮点偏差另按量化误差报告 |
| FIR 频响 | 通带波动建议不超过 1 dB，阻带建议至少 40 dB；设计前固定边缘频率和增益 |
| 动态执行 | 统计真实产品工作量对应的 PUSH/VRED；输出 FIR 支路无 VUPD 权值更新 |
| 加速 | 同输入、同系数、同数值规则下 FIR SIMD 总周期小于 RV32 标量；建议目标至少 2 倍 |
| 整机时间 | 音频生产路径最坏时间不超过期限；建议占用不超过 80%，完整统计交接开销 |
| 定位 | 已知位置声源测试，报告角度/位置误差及异常帧；沿用或重新冻结现有定位指标，不能只看峰值格号 |
| 定向增强 | 同次输入比较单麦与 DAS 的目标/干扰功率；建议受控场景至少改善 3 dB，保留无收益场景 |
| 输出可用 | 输出 PCM 样点连续、无新增点击或非预期饱和；记录总体延迟及方向切换瞬态 |
| 负例 | 破坏 FIR 系数或输出指纹必须 FAIL；重复/缺失输入序号必须被检测 |
| FPGA | 匹配目标器件的完整实现可用，建立/保持时序通过；不存在未解释的资源溢出或未约束路径 |

真实录音无法直接分离目标与干扰，因此板卡声学对照应增加目标单独播放、干扰单独播放及混合播放，并固定位置、音量和增益。随机说话不能替代可复验的功率对照。合成定点场景的增益不得直接标成真实房间增益。

| `scripts/verify.ps1`、PS 构建及整机对照脚本 | 更新必选项目、构建输入与结果地址 |
| `scripts/golden/`、`tb/` | 新增生产输入 DAS/FIR 参考及针对性测试 |
| `README.md`、`docs/acoustic_acceptance.md`、`docs/measurements.md` | 更新架构、验收范围和实测指标 |

## 九、风险与处置

| 风险 | 处置与完成条件 |
|---|---|
| 删除 GSC 后仍不实时 | 分解定位、搬运、音频处理的时间；调低定位刷新率或优化输入接口，必要时评估 PS 分担 |
| DTCM 不能存下真实八路帧 | 先核查容量和地址，采用有界分块或可达存储；禁止无预算新增大数组 |
| 阵列映射不支持八路历史 | 首版只做单路输出 FIR；八路扩展独立立项并验证资源与时间 |
| FIR 缺乏实际需求 | 根据频带与响应选系数；若业务需要的 FIR 很短，诚实报告加速受调用开销限制 |
| 转向结果与 GSC 内存耦合 | 先迁移结果区，再删除旧链接段，检查 PS、TB、参考数据的全部地址 |
| 错误转向降低 DAS 收益 | 校验延迟符号及参考点，加入方向置信度、迟滞和渐变，保存输入复现 |
| 补偿放大噪声或满幅溢出 | 限制增益，定义缩放/舍入/饱和，测试满幅和低幅值 |
| 旧验收被绕过后产生假 PASS | 新增独立结果、动态指令和破坏负例，不以程序结束或 LED 判断声学通过 |
| 多版本位流、ELF、LUT 不匹配 | 每次记录源码版本、SHA256、构建时间、目标器件和下载日志 |

## 十、排期与完成定义

首版预计 **11～18 个工作日**，按一名开发者、现有工具链可用、真实八路麦克风与板卡可测试估算。阶段 0～3 和阶段 5 构成首版；若需要新的生产输入 RTL 或大幅调整存储，应在阶段 0 后重新估时。八路 FIR 条件扩展另增加约 3～6 个工作日。

| 里程碑 | 可审查结果 |
|---|---|
| M0 | 基线、数据接口、预算及验收参数冻结 |
| M1 | 不含 GSC 产品路径的可运行镜像，原定位与转向回归通过 |
| M2 | 真实 PCM DAS 离线逐点验证、跨块输入和输出成立 |
| M3 | SIMD 输出 FIR 数值/频响/动态执行/加速验证通过 |
| M4 | 匹配产物的 FPGA 实现通过，真实八路输入连续运行验收完成 |

首版完成必须同时具备：真实输入、连续 DAS 输出、实际运行的 SIMD FIR、可复现的结果与时间对照、完整 FPGA 实现及板卡日志。仅删除 GSC 函数、编译成功或合成场景 PASS 均不足以宣布本方案完成。
