**规矩**：每解决一个问题，就在这里落一份单独的文件。写完在下面索引里加一行。
目的是工程做完之后能复盘——**尤其是那些"看起来像 A、其实是 B"的**，
因为那类问题每次都要重新花时间认一遍。

写法（尽量短，一页以内）：

```
**症状**     看到什么现象。要具体到能把人带到现场（哪条 TB 卡死、哪个数是几）
**误判**     一开始以为是什么（如果走过弯路，写下来——这是这份档案最值钱的部分）
**根因**     实际是什么
**修法**     改了什么，改在哪
**复现/指纹** 下次怎么最快认出来
```

编号不重用。索引一行一个问题，状态分 `已修` / `待修` / `已绕过`。
