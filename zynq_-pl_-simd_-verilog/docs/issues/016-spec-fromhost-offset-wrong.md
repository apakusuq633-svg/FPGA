# 016 规格里 fromhost 偏移写错

**症状** 无——**这才是最危险的**。

**根因** 我写规格时告诉上板程序 `fromhost` 在 AXI `0x044`，实际是 **`0x03C`**。
`0x044` 是 `ADDR_CYC_BUSY`，**写进去是静默 no-op**。串口上看不出任何异常，
只是宽带支路一直没关掉。

**修法** 按 `0x03C` 实现。

**复现/指纹** **"寄存器写了没反应"要当成一级嫌疑**，不要假设"写了就是生效了"。
判据：写完**回读**。上板程序里现在每一处配置都回读（NBVER 写 0x5A5A 读回来
就是为了证明 0x200 那个窗口真的在解码）。
