# 033 逆变换反向拆分取错下标：Nyquist 当成 DC 用

**状态**：已修
**日期**：2026-09-22
**阶段**：Stage 1（GCC-PHAT 固件内核）
**复现**：`scripts/golden/fw_gcc_model.py` 的第 ① 段自检

---

## 症状

GCC-PHAT 要一次**实数逆变换**（Hermitian 频谱 → 实序列）。为了省 DTCM，
逆变换走的是正变换的镜像路线：**反向拆分 → 512 点复 IFFT → unpack**。

先测「往返」：任意实序列 → 正变换 → 逆变换，应当还原。实测：

```
往返 1024 点：标度 1/1021，最大残差 2675 (输入峰值 19992)   ← 13%
```

**标度是对的**（1021 ≈ 1024），**序列形状也大致对** —— 不是那种一眼就能看出
的乱码，而是"像，但每个点都差一点"。这种残差最容易被当成"定点舍入就这样"
而放过去。

## 误判

第一反应是**定点精度不够**：逆变换有 9 级 `>>1`，加上正变换的 9 级，18 次
舍入，残差十几个百分点"似乎说得过去"。

差点就去改成分块浮点或者加宽数据通路了 —— 那是**方向性错误**，会把一个
一行就能修的下标问题，做成一次伤筋动骨的精度改造。

**把它拦住的是「先量再改」**：把同一套公式写成浮点版跑一遍：

```
浮点逆变换公式: 标度 0.001953125  最大残差 0.00
```

**浮点版残差是 0。** 公式在数学上完全正确 ⇒ 残差不可能是"精度不够"，
只能是定点实现里某个下标/移位写错了。

## 根因

反向拆分的核心一步是：从 Hermitian 频谱 `Ψ[0..M]`（N = 2M = 1024）还原出
偶/奇子序列的频谱 E、O，再拼回 Z。

用到的关系是

```
X[k+M] = conj(X[M−k])          ← Hermitian 对称
```

**关键是 `M−k` 不取模**：

| k | M−k | 是哪一条 |
|---|---|---|
| 0 | **512** | Nyquist（第 512 条）|
| 1 | 511 | |
| 511 | 1 | |

我写成了 `mk = (M − k) % M`，于是 **k = 0 时取到的是第 0 条（DC），
把 DC 当成了 Nyquist 用**。

只错一条 bin，而且那条的幅度通常不大 —— 所以序列**形状**还对，
残差是 13% 而不是 130%。

## 修法

`fw_gcc_model.py` 里：

```python
mk = M - k          # ← 不取模。k=0 时是第 512 条（Nyquist），不是第 0 条
```

同一处修进 `sw/fw/fw_fft.c` 的 `ifft512_real()`，并在函数头写了这条警告。

修完：往返残差 **RMS 0.73 LSB**。

## 复现指纹

- **标度对、形状大致对、每个点差一点** ⇒ 优先怀疑**下标**，不要先怀疑精度。
- 判据的写法很关键：**别按最大残差占峰值的百分比卡**。这里的输出是整数、
  量级只有 ±20，1 LSB 就相当于输入的 5% —— 按百分比卡会把正常舍入判成错。
  要卡就卡**「残差 RMS 折合多少 LSB」**（这里是 0.73）。
- 最快的分离手段：**把同一套公式写成浮点版**。浮点版残差为 0 ⇒ 公式没错，
  定点版有问题；浮点版也错 ⇒ 公式错了，别去查移位。

## 同轮踩到的另外两个（都属于「参照自己错」）

1. **浮点参照的算子顺序写反了**。定点版算 `G = FFT(A)·conj(FFT(B))`，
   浮点参照写成了 `FFT(B)·conj(FFT(A))` —— 峰值整体取负。现象是
   「定点算出 +7，golden 说 −7」，看着像定点链路有符号错误。
   **参照和被验对象必须用同一个约定**，这句话要写进参照的注释里。
2. **断言阈值是照抄上一个内核的**。FFT 那边的「5%」是相对 Q15 满幅说的，
   搬到相关的整数序列上就不成立。**判据要跟着被测量的量纲走**。
