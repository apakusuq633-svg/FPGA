# 098：实时定位分数为零，低电平定点输入缺少幅度归一化

**症状**：独立定位读取接入后，序号持续更新，但 30 秒 57 次读取峰值和次峰值均为 0，定位点无法显示。

**误判**：定位点未显示并不只是 GUI 未接接口；原音频通路验收也没有证明定位算法在真实输入下有效。

**根因**：四麦环境声只有数十个 PCM 量化单位，定位 FFT 逐级缩放、互谱再右移 15 位，低电平信号容易在 PHAT 白化前量化为零。真实音频未做定位专用的输入幅度归一化。

**修复**：四麦定位输入读取并统计原始电平后，只对临时 1024 点定位缓冲做整数二次幂放大，峰值达到 8192～16383，满量程输入不放大、静音保持零；给定真实峰值时不溢出。PHAT 本身消除幅度，缩放用于保留定点精度。DAS 音频、PS 诊断、麦克风原始电平统计均不使用这个缩放后的缓冲。保留 `best>0 && best>second` 的有效峰值判定，不强行展示并列峰值。

**复现与验证**：更新前 `build/das4/live_board_location_1.json`：定位帧增加 663，57/57 次 best=second=0。更新后 `build/das4/live_board_location_scaled_1.json`：定位帧增加 633，27 个不同网格，25/57 次唯一有效峰值，best 范围 0～3357；29 个新音频帧、2274 块，最大诊断 322 ms，PL/PS 丢样及段重置均为 0。`sw/ps_location_scale_test.c` 检查静音、低电平、满量程及全部峰值范围；序号保护测试拒绝撕裂定位快照。两轮环境声并非同一份录音，这些结果证明恢复非零定位计算，不证明受控定位精度。
