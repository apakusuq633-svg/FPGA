# 042 定点 CIC 的梳状级不回绕 ⇒ 输出随位宽发散，位宽试验全是废的

**症状** Python 定点模型 `cic_fixed` 对全 1 输入的输出范围随 `acc_w` 一起涨：

```
w=16 → ±196608      w=20 → ±2883584      w=24 → ±50069504
```

而正确值恒为 `D^N/2`（居中后）。同时 §4 的「最小可用位宽」扫描给出
**14 位就够**这个荒谬结论（真实需要 20 位）。

**误判** 一度以为这是 CIC 的正常现象（「常值输入下积分器本来就无界增长」），
差点把它当成「回绕本来就是对的」的证据写进结论。**方向正好相反**：
无界增长的是**积分器**，梳状级必须把它差分掉，这一条才是「回绕无害」的前提。

**根因** `cic_fixed` 只让**积分器**按 `acc_w` 位回绕，梳状级用了任意精度。
真 RTL 里每一级寄存器都是 `acc_w` 位。两边算术不一致，比出来的东西没有意义。

**修法** 每一级都过 `sgn()`：`v = acc[k] = sgn(acc[k] + v)`、
`t = sgn(w - comb_prev[k])`。改完实测：N=3 最小 20 位
（= `1 + ceil(log2 D^N)`，与解析式吻合），RTL 取 24。

**顺带修掉一个空判据** 同一段原本用 `(ref-got) mod 2^w == 0` 当判据 ——
**回绕版恒满足它**（两边本来就差整数个 2^w），所以任何位宽都「通过」。
判据必须是 `got == ref`（梳状链不减直流，CIC 对常数的响应就是 D^N）。

**复现指纹** 被测模型的输出幅值**随位宽单调变大** —— 只要看到这个，
就是某一级漏了回绕，而不是「位宽不够」。
