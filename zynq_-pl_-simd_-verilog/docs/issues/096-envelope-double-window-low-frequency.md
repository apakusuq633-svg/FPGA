# 096：包络谱双重加窗产生低频伪影

**症状**：真实通路 GUI 的包络谱前三点接近 1:1:0.5，低频幅值很高。音频谱首组还把 DC 与约 0～148 Hz 混在一起。

**误判**：仅凭图形会把首组峰值误认为 PL 去直流没有生效。实际 PL 的一阶高通已接入，首组是 32 个频点的最大值，并非独立 DC。

**根因**：训练兼容特征链先对音频加 Hann 窗，再提取带限解析包络，减算术均值后再次加 Hann 窗。第一次窗引入包络起伏，第二次窗使减均值后的 DC 再次非零。无调制纯音也能复现。

**修法**：GUI 展示包络单独使用未加窗音频提取 1400～4600 Hz 带限解析信号，再去 Hann 加权均值、加一次 Hann；DC 不参与绘图归一化。音频谱用加权去均值的窗口，原窗口 DC 单独报告。数值误差低于 1e-9 的谱不放大。分类继续使用训练兼容算法，页面明确注明两者区别；本次不声称已修正分类特征或完成重新训练。

**复现/指纹**：`scripts/check_ps_apps.py` 执行 `sw/ps_display_test.c`。39062.5 Hz 采样、8192 点 FFT、第 419 格载波、0.2 幅值、0.3 偏置：旧最低频格约 204.804166，修正后前三个低频格最大 2.0948611e-12（宿主实测）。第 21 格调制峰仍在第 21 格；常值输入不显示被放大的数值噪声，削波统计为 40000。真实上板记录与当前处理时延见 [GUI 更新](../gui_signal_validation.md)。
