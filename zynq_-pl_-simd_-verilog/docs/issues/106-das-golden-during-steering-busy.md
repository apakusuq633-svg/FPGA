# 106 测试参考在转向更新忙时错误退回零延迟

状态：已修。四麦17帧/34535点、16麦8帧/88919点完整持续逐位通过，均丢样0；四麦声源恢复后仍一致，16麦最终16路几何补偿与256点稳定增强通过。

**症状**：四麦声源→直流→声源测试在重新捕获后样点33990报告音频不一致，此前声源和DC拒绝阶段通过。

**误判**：初看像DAS插值或重新捕获时丢失音频历史。

**根因**：生产DAS在已转向后遇到steer_busy时保留上一份采样快照；TB却把busy解释为本样点使用零延迟。并且TB在真正输入边沿之前计算状态，存在方向更新撞上输入边沿的机会。

**修法**：四麦/16麦TB在输入有效边沿前读取转向状态；独立保存上一份已接受的几何补偿，busy期间保持，与DAS接口契约一致。逐位音频对照仍保留，不通过跳过忙期间样点掩盖错误。

**复现/指纹**：`powershell -File scripts/check_live16_xsim.ps1 -Debug4`；须完成声源确认、纯DC拒绝且方向不变、声源重新捕获，并对每个连续DAS/FIR样点核对。16麦生产3/3/64渐变策略由`-Natural`持续测试。
