# 014 PS 侧 prominence 差 8 个八度

**症状** README §9.1 写的 6 dB 门限，实际行为是 −18 dB —— 噪声峰大量漏过，
每帧伪造出 2~6 个候选。

**根因** 实现写成 `log2_q8(ratio_q8) - 8`，而 Q8 定标让比值大了 2^8 倍，
于是 4 倍功率被判成 **30 dB 而不是 6.02 dB**（正好差 8 个八度）。

**修法** 改成对数域相减 `log2(p) - log2(p_local)` —— 无除法、不会溢出。
修后同一场景伪候选从每帧 2~6 个降到 1~3 个，真音仍在第 5 帧进 ACTIVE。

**复现/指纹** 在 Q 格式里"先算比值再取对数"必然带一个 2^k 的偏置，
而**偏置是常数、看起来就像一个"偏保守/偏激进的门限"**，不会报错。
判据：拿一个已知倍率去测（4 倍功率必须落在 6.02 dB）。
