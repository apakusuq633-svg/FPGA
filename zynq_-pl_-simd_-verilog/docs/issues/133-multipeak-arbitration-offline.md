# 多峰竞争离线修复：联合频带仲裁与覆盖优先（2026-10-27）

## 结论与适用边界

已修复两处由源码和合成测试确认的仲裁偏置，完成离线回归与A9构建。未上板，不能宣称现场60–70度/85度竞争已经消失，也不能据此认定85度峰总是真实声源。没有扩大角度、按目标位置选峰或强制只输出一个峰。

## 修改前证据

1. sw/circular9_candidates.c旧逻辑按rank再band遍历，低中高频依次向3个输出槽写入。槽满后新的独立方向不再参与竞争，存在频带顺序偏置。合并时只因两个峰相距15度以内，就累加band_mask；代表角度取某个单频带较高峰，其他频带的分数/时间支持不一定对应这个角度。
2. sw/ps_circular9_aux.h旧合并按OBSERVED/RECOVERING/COASTING分层，同层固定主定位优先。一个刚观测到的主定位近邻可以遮掉已有完整1.024秒覆盖的辅助方向，导致诊断资格受来源优先级影响。
3. 修改前完整三源/管线回归均通过，日志c9_peak_before.log、c9_pipeline_before.log保存。本修复不是声称旧代码全面不可运行。

## 最小实现

- 每频带仍最多3个、最多9个合格峰先全部进入池，再按各代表角度的联合频带支持排序，最终仍最多3个。
- 每个贡献频带在同一代表角度重新检查原评分/肩峰区分与至少3个真实STFT观察支持，不再借用邻峰的时间证据。支持区间来自一个实际连续观察段，不用无证据并集凑覆盖。
- 同频带只算一次，候选排列不会影响结果；同分用明确的分数/支持/网格规则决策。不偏爱大角度、低频或高频。
- 合并主/辅助轨迹时先比状态，再比是否满足原90%完整诊断覆盖，再比实际观察次数、新鲜度和ID。只选既有轨迹，不转移或伪造ID。
- 原25度单频带NMS、15度融合、12度轨迹关联、3次观测、90%覆盖、200ms新鲜度等门槛不变。小于这些角间隔的真实源仍有分辨限制；没有把多个提议等同多个电机。
- GUI继承实时提议始终显示、250ms元数据、1秒新快照双谱；声孔坐标X22/Y25.5/斜向23mm暂按45度不变。

需要实板检查辅助搜索是否仍满足200ms新鲜度、跳步/拒绝/诊断快照频率和采样丢失。若负担明显增加，先回退旧包，再按实测优化，不提高超时掩盖。
