# 015 峰值插值在功率域有系统偏差

**症状** 240 Hz 的音被报成 **235.7 Hz**（0.11 bin 偏差）。

**根因** Hann 窗主瓣不是抛物线，在**功率域**做三点抛物线拟合有系统偏差。

**修法** 改成对 `log2` 功率拟合。偏差降到 ≤0.017 bin（240 Hz → 240.65 Hz）。
bin 2..500 一样准；只有峰值落在 bin 1（≤76 Hz）且偏移 <0.15 bin 时，
因 DC 与负频像耦合最大到 0.2 bin。

**复现/指纹** **偏差是单向的、随频率系统变化** → 是插值公式的问题，不是随机噪声。
用已知频率的合成音扫一遍就能看出来。
