# 043 解析噪声积分漏了双边谱的 ×2 ⇒ 稳定偏 +3.01 dB

**症状** `pdm_decim.py` §5b（真白噪声过 NTF+CIC，量带内噪声）与 §3 的解析积分
差 **恒定的 +3.11 ~ +3.28 dB**，四个配置（L=2/4 × N=3/4）全都一样。

**误判** 恒定偏差最容易被解释成「物理」——当时就写下了
「一位量化器噪声非白的固有近似误差，±3 dB 可接受」这样的结论，
**并且已经把它写进脚本输出**。差一点就当成结论收工。

**根因** 「四个配置偏差完全一致」这个特征是信号，不是噪声：
真随机的模型误差不会这么整齐。实际是归一化口径不一致：

- 解析积分 `acc(f)` 是**双边**功率谱密度（对正负两侧的频率都做了折叠求和）
- 仿真用 `np.fft.rfft` 出来的**单边**谱，`psd = 2|Y|²/(Fs·N)`
- 而信号那边用的是实正弦功率 `A²/2`（单边口径）

差正好一个 2 ⇒ `10log10(2) = 3.01 dB`。

**修法** `band_noise()` 的返回值 ×2，并注明「带内噪声功率是正负两侧之和，
必须和信号的实正弦功率同一口径」。

**复现指纹** **多个互不相关的配置报出同一个偏移量** ⇒ 一律先查归一化/口径，
不要往物理上解释。修完之后 §5b 四个格子差 ≤ 0.3 dB，§5 剩下的 ~1.7 dB
才是真正的「量化噪声非白」近似误差。
