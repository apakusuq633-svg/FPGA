# 009 限幅伪装成"没收敛"

**症状** NR 卡在 **4.5 dB** 上不去，权重看着是在动、但输出总是饱和。

**误判** "算法收敛不够快 / μ 不对"，反复调 μ。

**根因** 初级幅度定得太大，抵消所需输出约等于 `|P|/|S|` 倍初级，
超过了 `Y_LIMIT` —— **窄带一直顶在限幅上**，被自己削平了。
`SCALE` 当时是 12000，改成 10000 并把 `Y_LIMIT` 从 8191 提到 30000 后正常。

**修法** 调 `SCALE` / `Y_LIMIT` 使输出峰值离限幅有余量（现在实测峰值远低于限幅）。

**复现/指纹** **NR 卡在一个具体数字上、怎么调 μ 都不动** —— 那就是被限幅了，
不是收敛问题。先打印输出的峰值和限幅值比一比。
