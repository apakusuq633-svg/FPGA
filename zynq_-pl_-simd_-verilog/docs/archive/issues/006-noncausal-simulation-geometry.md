# 006 仿真几何非因果

**症状** 宽带支路单独只有 **1~7 dB**，怎么调 μ 都没用。

**误判** "算法没调好" —— 在 μ、ρ、抽头数上兜了很久。

**根因** 被控对象几何反了。要抵消需 `g·y(n−dS) = −gp·x(n−dP)`，即

```
y(n) = −(gp/g)·x(n + dS − dP)
```

要让 `y(n)` 只用到 `x(≤n)`，就得 **dP ≥ dS**。原先写成 **dP=3 / dS=8**，
等于要求"预测未来 5 拍"。窄带靠 NCO 还能装过去（音调可预测），
**宽带支路结构上不可能收敛**。

**修法** 改成 dP=16/17、dS=8/9/10。物理含义：**参考麦必须比误差麦更靠近噪声源**。

**复现/指纹** "窄带能跑、宽带跑不动"这个**不对称**是关键指纹 ——
两者共用同一套自适应框架，唯一的结构差别就是窄带参考可预测、宽带不可预测。
上板摆位前必须把这条算清楚。
