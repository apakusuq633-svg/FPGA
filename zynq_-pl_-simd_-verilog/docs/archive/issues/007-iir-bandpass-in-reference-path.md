# 007 参考通路放 IIR 带通

**症状** 宽带支路单独 **20.86 dB → 1.80 dB**，差 19 dB。修好 006（因果几何）后仍然只有 1.7 dB。

**误判** 先怀疑陷波把宽带源挖掉了（那个方向也确有独立问题，见 021）。

**根因** ANC 的 FIR 要实现的是 `w = −P/(S·H_BP)`。§14 想要的两级 IIR
（50 Hz 高通 + 300 Hz 低通）**在直流有二阶零点**，它的逆就是直流上的二阶极点 ——
64 抽头**结构上实现不了**，FxNLMS 于是收敛不了。
另外 IIR 的**频率相关群延迟**还吃因果余量（高 Q 陷波尤甚），
而线性相位 FIR 的群延迟是常数、能被次级通路模型吸收。

**修法** 第一版按**直通**做：§14 的"约束到 50–300 Hz"由**声源本身的带限 + 被控对象**
保证。`BP_COEFS` 仍然算好写进 `sw/anc_params.vh`，留给第二版换线性相位 FIR。

**复现/指纹** 把参考通路上的**任何 IIR** 摘掉试一次 —— 这种"差 15 dB 以上"的台阶，
通常不是调参能补的，是结构不匹配。**ANC 参考通路上只该有线性相位的东西。**
