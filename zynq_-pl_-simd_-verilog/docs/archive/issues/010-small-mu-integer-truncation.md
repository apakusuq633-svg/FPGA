# 010 小 μ 下整数截断

**症状** μ 调**小**反而更差：`MU_NUM=2^23` 时宽带单独 **−8.80 dB**（误差变大了 7.6 倍）。

**误判** "调小了应该更稳" —— 所以看到变差时第一反应是别的地方错了。

**根因** 更新量被两次 `>>15` 截断：

```
g = (μ_eff·e) >> 15          # 第一次截断
Δw = (g·x') >> 15            # 第二次截断
```

μ 小时两次截断把 Δw **截成 0**，更新死掉。更糟的是 `>>` 是**向零取整**，
正负不对称 —— 于是权重单方向漂移，表现为**发散**而不是"不收敛"。

**修法** 把信号电平提到满量程附近（`SCALE` 10000、`Y_LIMIT` 30000），
使 Δw 有 4~6 个 LSB，截断不对称只占 10% 而不是 100%。

**复现/指纹** **μ 越小结果越差** —— 这个方向性是反直觉的，见到就往截断上想。
配合 009 一起看：两个都是"NR 上不去"，但这个是**变小 μ 会恶化**，
那个是**调 μ 完全不动**。
