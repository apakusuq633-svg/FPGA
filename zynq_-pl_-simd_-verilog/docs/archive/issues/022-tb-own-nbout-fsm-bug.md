# 022 TB 自己的 NBOUT 采样 FSM 有 bug

**症状** `tb_anc_hybrid` 里核被"毒死"：`got_n=12`、PC 变成 `000003XX`。

**误判** 先怀疑固件、再怀疑 RTL 的 FIFO 逻辑。

**根因** **TB 自己**的 NBOUT 采样状态机是 **2 拍自由循环**，
与 1024 拍的帧周期**相位锁定** —— 于是每帧的参考补料都被它屏蔽掉。
FIFO 抽干后弹出**未写的 X**，X 灌进核，PC 就废了。

**修法** TB 侧把补料改成**绝对优先**（else 分支护住观测），FIFO 水位稳在 12。

**复现/指纹** **"TB 死了但 RTL 没问题"** —— 这类要先怀疑 TB 自己和 DUT 的时序耦合。
配套的判据很有用：TB 里直接断言 `fifo_empty` 在 tick 上**从来没有效过**
（`empty_n == 0`）。没有这条断言，X 灌进核只会表现为"核莫名其妙跑飞"。
