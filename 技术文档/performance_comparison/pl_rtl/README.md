# 当前九麦 PL 独立 RTL 性能试验

本目录只包含独立试验，不修改生产 RTL、生产固件、规范镜像或根目录执行入口。正式数据来自 2026-10-28 的当前源码重建与实际 RTL 仿真；没有运行综合，也没有连接 FPGA 板卡。

## 一键重跑

在工作区根目录执行：

```powershell
C:/msys64/ucrt64/bin/python.exe -X utf8 performance_comparison/pl_rtl/run_pl_measurements.py
```

默认重建独立镜像，运行 32 个重叠九麦定位窗及 FFT/FIR 两组对照。`--reuse` 只适用于本目录源码、驱动与工具链未改变的情况，复用本次模型与定位固件；微测固件仍重新编译。`--only soc` 或 `--only micro` 可单独执行，`--windows N` 可调整定位窗数。依赖路径写在脚本开头，现为 MSYS2 UCRT 的 Python/GCC/Verilator 与 AMD 2025.2 的 RV32 GNU 工具。

## 正式结果与范围

实际 testbench 时钟周期 25 ns，即 40 MHz，以下毫秒直接按 `cycles / 40000` 换算。仿真在宿主机花费的 wall time 不作为芯片执行时间。

| 任务 | 标量周期 | 扩展指令周期 | 标量时间/ms | 扩展时间/ms | 加速比 |
|---|---:|---:|---:|---:|---:|
| 1024 点实 FFT | 179036 | 6602 | 4.475900 | 0.165050 | 27.118449× |
| 512 点、32 抽头 Q15 FIR | 276774 | 15138 | 6.919350 | 0.378450 | 18.283393× |

FFT 两路实际运行同一 `fw_fft.c` 中的标量与硬件入口，使用同一 1024 点确定性输入，513 个复数、共 1026 个 int16 输出逐项一致。扩展入口包括 3088 拍装载、919 拍 RUN 指令等待、2577 拍取回，以及函数/时间戳开销；纯 FFT 引擎是 917 拍。内部测量时间戳开销没有扣除。

FIR 直接计时未修改的 `fw_fir_run(0/1)`，同样输入与 `fw_fir_coeff.h` 中的同一组 32 个系数，含历史初始化、输入生成、点积、右移、限幅和校验和，不含预装系数。testbench 观察原函数退休时的校验和累加，通过相邻累加值的差恢复每一个已限幅输出。标量和 SIMD 各 512 点均与独立 Python 整数卷积逐项一致，双校验和也一致。它是时域 FIR 算子对照，不等同于九麦整机全部连续拾音链路的加速比。

九麦当前配置为 9 个有效通道/10 个采集槽、1024 点窗/512 点 Hop、36 麦对、64 点相关环、1024 个空间网格与四麦对并行 SRP。32 窗正式结果如下：

| 定位计时边界 | 最小/拍 | 最大/拍 | 时间范围/ms |
|---|---:|---:|---:|
| 各自窗内首个对齐 PCM → RV32 稳定偶数结果发布 | 366893 | 367049 | 9.172325–9.176225 |
| 固件记录的窗后处理，含 RV32 后处理 | 104919 | 105071 | 2.622975–2.626775 |
| 最后一个对齐 PCM/原始窗就绪 → SRP 的 1024 个评分全部写完 | 82264 | 82354 | 2.056600–2.058850 |
| 定位搬运计算到 best 网格读完，尚未进行 RV32 后处理 | 84312 | 84402 | 2.107800–2.110050 |
| RV32 峰值、质量与结果整理 | 20607 | 20669 | 0.515175–0.516725 |

首样计时对每一窗重新锚定 `first_sample`，包含完整窗内的 1023 个采样间隔，即 261888 拍/6.5472 ms。输入样点编号连续，4096 点确定性波形循环读取，窗首为 0、512、…、15872。评分完成以 SRP `busy` 下降/`done` 被观察为边界，不含随后 2048 拍的 best 网格遍历与 RV32 后处理。窗口就绪时间以最后样本的原始缓存提交为依据；本夹具中该拍数与最后 PCM 到评分的结果一致。

滚动统计在采集期间完成，属于当前架构前移且重叠的工作。与纯标量定位比较时，应使用“原始窗已就绪→全部评分完成”的共同边界，并写明该前置重叠工作及不同输入存储布局。`stage_cycles.csv` 中的状态驻留含指令请求/等待与搬运，不能直接当作纯算术引擎周期。首窗状态和计算寄存器相差 6 拍，属于就绪/状态交接锚点差异，不能将两者混加。

32 窗各有 9 次正 FFT、36 次互谱、36 次 PHAT、36 次 IFFT 与 1 次 SRP 的实际计算指令退休，累计 288/1152/1152/1152/32。45×32 个采集统计字与输入独立计算一致，没有窗口或连续音频丢失。FFT/IFFT 引擎各为 917/854 拍；SRP busy 区间为 9306 拍，其起点与模块级 start→done 的 9307 拍口径相差一拍。

该夹具从对齐后的九路 PCM 注入，不包括物理麦克风、模拟声学环境、PDM 到达过程、PS 接收、DDR DMA 或网络。生产配置仍未确认物理几何，不声明可信实际转向。连续 DAS/FIR 与定位并发，但夹具预装的是单位脉冲系数；81 拍输入到 FIFO 只表示该配置下的数字服务时延，不表示实际滤波器群延时。

## 文件与复核

- `results.json`：最终完整机器可读结果，各定位数组均为同次 32 窗运行；`summary.csv`：算子及逐窗计时；`stage_cycles.csv`：逐窗状态聚合。
- `logs/*.log`：当前有效构建与仿真原始 stdout/stderr；同名 `.attemptNN.log` 和其他明确命名的调试日志是历史尝试，不参与正式汇总。
- `inputs/`：确定性 PCM、FIR 系数及输入说明/hash。`soc_dump/`：逐窗评分/统计、首窗频谱/相关/原始环和 scratch。`micro_dump/`：完整 FFT/scratch 与原函数退休恢复的 FIR 输出。
- `source/`：隔离的生产源镜像。`micro_fw/` 与镜像的 `build/circular9/fw/`：ELF、映射、二进制、HEX。`soc_model/`、`micro_model/`：Verilator 产物。
- `source_hashes.json` 与 `production_integrity.json`：生产输入源前后哈希；`artifact_hashes.json`：输入/固件/dump 哈希；`experiment_driver_hashes.json`：本试验驱动哈希。

## 工具链装载约束

这套 AMD GNU 工具默认插入 36 字节 `.note.gnu.build-id`，使 `_start` 和 `.text` 的 ELF 地址变成 `0x24`。如果只将 `.text` 转为二进制并从 ITCM 地址零加载，会造成 PC 相对地址偏移 36 字节；调试中表现为 BSS 清零侵入 FIR 系数区。这些早期尝试未计入正式结果。

试验仅在隔离构建参数增加 `-Wl,--build-id=none`，使 `.text` 与 `_start` 均从零开始。生产脚本没有修改。入口与节表断言记录在 `logs/circular9_elf_headers.log`、`logs/micro_elf_headers.log`，所有正式数据均通过入口为零的构建。旧的反汇编日志仍保留，可直接看到 `0x24 <_start>`；当前有效反汇编显示 `0x0 <_start>`。
